# Data Quality | OpenMetadata Quality Management Guide

Official documentation overview of OpenMetadata's Data Quality framework (v1.12.x). Provides a high-level summary of data quality monitoring capabilities: native tests for all database connectors, alerting system, health dashboard, and resolution workflow.

## Key Points

- **Native tests** at table and column level for all supported database connectors
- **Alerting system** for notifications on test failure
- **Health dashboard** for real-time test failure tracking and prioritization
- **Resolution workflow** to inform data consumers on test resolutions
- **Extensible** architecture adaptable to organization needs
- Integration with **Data Profiler** for combined profiling and quality testing
- **No-code** platform for building, deploying, monitoring, and configuring quality alerts

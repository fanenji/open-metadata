# OpenMetadata MCP — Official Page

Official marketing page for OpenMetadata's **embedded MCP Server** (v1.8.0+). Highlights the architectural integration with OpenMetadata's authorization engine, enabling MCP clients (Claude, Cursor, OpenAI) to read from and write to existing integrations, assuming any role or policy defined in the platform.

## Key Points

- **Embedded architecture**: MCP Server uses the same authorization engine as OpenMetadata APIs
- **Use cases**: intelligent pipeline monitoring, generating dashboards from metadata analysis, automated data glossary creation
- **MCP Meetups**: dedicated community sessions (May 2025 introduction, June 2025 update)
- References the [[mcp-server]] already documented in the wiki

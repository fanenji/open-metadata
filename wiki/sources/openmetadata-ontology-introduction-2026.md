# OpenMetadata Ontology Introduction

Introduction to the OpenMetadata RDF/OWL ontology, part of the [OpenMetadata Standards](https://openmetadatastandards.org/) project. The ontology provides semantic definitions of all metadata concepts using W3C standards (RDF, OWL).

## Key Elements

- **File**: `rdf/ontology/openmetadata.ttl`
- **Namespaces**: `om:` (`http://open-metadata.org/ontology#`), `rdf:`, `rdfs:`, `owl:`
- **Purpose**: formal semantic definitions, knowledge graph integration, SPARQL querying, semantic reasoning
- **Related**: [[ontology-explorer]], [[knowledge-graph]], [[rdf-ontology]]

## Relevance

This source documents the formal semantic web foundations that underpin OpenMetadata's [[ontology-explorer]] and [[knowledge-graph]] features (v1.13).

# OpenMetadata Unified Knowledge Graph — Research Query

An Italian-language research conversation (February 2026) exploring what the OpenMetadata Unified Knowledge Graph is, how it works, and how it integrates with existing data catalogs.

## Key Points

- **Centralized graph-based repository** unifying metadata from diverse sources with entities as nodes and relationships (lineage, ownership) as edges
- **Pull-based ingestion** via 100+ connectors, populating nodes and edges from databases, pipelines, dashboards
- **Schema-first architecture** with graph storage for scalable queries (keyword search, associations, lineage tracing)
- **Integration with existing catalogs**: bidirectional ingestion via connectors for DataHub, Amundsen, Atlas, Alation, Collibra — enabling federation without forced migration
- **Governance**: versioning, tags, compliance enforcement through the interconnected graph

Confirms and expands on the [[unified-metadata-graph]] concept already well-documented in the wiki. Provides additional details on catalog federation capabilities.
